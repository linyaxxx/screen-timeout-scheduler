屏幕省电时段 v1.1

本版更新
重做了界面：圆角窗口、绿色主题、全天时间轴、星期按钮和登录启动开关。
原版配置文件兼容，无需重新设置规则。更新前请先从托盘退出旧版，再替换 exe。

快速开始
1. 把文件夹放在准备长期保存的位置，双击“屏幕省电时段.exe”。不需要安装 Python 或其他工具。
2. 默认每天 08:00–12:00、13:30–17:30，无操作 15 分钟后关闭屏幕；其余时间（包括午休）为 1 分钟。
3. 点击“保存并启用”，规则立即生效。首次打开只展示设置，不自动修改电源设置。
4. 如需每天自动运行，打开“登录后自动启动”开关，再点“保存并启用”。之后不要移动或删除 exe；如果移动了，重新打开程序并保存一次。
5. 关闭窗口或点击“收起到托盘”后，程序继续运行。双击右下角显示器图标打开设置；图标可能在托盘折叠菜单里。

自定义
- 工作时段、其余时间的等待分钟数都可修改，范围是 1–1440 分钟。
- 直接点击时间输入框修改，格式为 24 小时制 HH:mm，例如 08:00、13:30。
- 支持添加多个时段、点击右侧垃圾桶删除时段、选择适用星期。默认周一至周日全部选中。
- 时段包含开始时间，不包含结束时间。因此 12:00 即切换为 1 分钟，13:30 切换为 15 分钟，17:30 切换为 1 分钟。
- 结束时间早于开始时间，表示跨午夜。例如选择周五、22:00–02:00，周六凌晨 02:00 前也属于该工作时段。日期选择按时段开始的那一天计算。
- 重叠或相邻时段按连续工作时间处理。未选中的日期使用“其余时间”规则。
- 修改后点击“保存并启用”，未保存的界面修改不会影响正在运行的规则。
- 左侧显示实际运行状态；尚未启用时明确标记为规则预览。时间轴预览当天的工作/其余时段，竖线表示当前时间。
- Ctrl+S 可保存并启用，Esc 可收起到托盘。

暂停、退出、取消自动启动
- 点击“暂停并恢复”，停用自动切换，并恢复工具接管前的关闭屏幕设置。暂停状态会保存，下次启动仍为暂停。
- 右键托盘图标，选择“退出并恢复原设置”。此时程序完全退出。下次打开会继续使用之前保存的启用状态。
- 要彻底停用：关闭自动启动开关并“保存并启用”，然后“暂停并恢复”，最后右键托盘退出。之后可删除工具文件夹。
- 如果程序运行期间你手动修改了 Windows 的关屏时间，启用状态会继续执行已保存的规则；暂停或退出时尽量保留后来手动设置的值。
- 如果切换电源计划，程序会跟随当前计划，退出时恢复它修改过的各个计划，不主动切换回旧计划。

运行方式与边界
- 适用于 Windows 10/11 桌面系统，使用 Windows 内置 .NET Framework 4.x。通常无需管理员权限。
- 使用系统本地时间，约每 5 秒检查一次；时间边界后最多约 5 秒更新。电脑休眠期间不唤醒电脑，恢复运行后重新判断时间段。
- 插电和使用电池时的关屏等待时间都会修改，分别保存和恢复各自的原值。
- “15 分钟 / 1 分钟”是连续无鼠标键盘操作的等待时间。到达时段边界时更改等待时长，不会立即发出强制关屏命令。
- 只修改 Windows 的“在此时间后关闭显示”设置，不修改电脑睡眠、休眠、自动锁屏、锁屏后的关屏时间或屏幕保护程序。
- 如果电脑设置为更早睡眠，实际会先进入睡眠；播放视频、会议软件或其他保持屏幕常亮的软件也可能阻止自动关屏。
- 多个显示器使用 Windows 的统一关屏超时，不分别控制每台显示器。
- 公司管理策略或其他电源管理软件可能限制/改写这些设置。界面会显示错误并重试，请以实际状态为准。
- 工具需要保持运行。关闭窗口会留在托盘；强制结束进程或突然断电无法当场恢复，备份会保留供下次启动恢复/继续使用。

数据
配置、原设置备份和简短日志保存在：
%LOCALAPPDATA%\ScreenTimeoutScheduler
settings.xml：规则与启用状态。
original-settings.xml：原始关屏设置的恢复备份。不要在工具运行或恢复失败时删除此文件。
activity.log：设置切换和错误日志，超过约 256 KB 自动清空。
自启动使用当前用户的 Windows 登录启动项，不创建管理员计划任务。不访问网络。

开发验证
源代码在 src 文件夹；运行 build.ps1 可用 Windows 自带 .NET Framework 编译器重新构建。
--self-test --report 路径 --data-dir 路径：执行时间规则、恢复和持久化测试，不改系统电源设置。
--power-test --report 路径 --data-dir 路径：同时测试真实 Windows 设置读写，并在 finally 中恢复原值。
--preview 图片路径 --data-dir 路径：生成界面预览，不修改电源设置或启动项。
--preview-scale 1.5：按指定像素比例生成预览，默认 1。
--ui-test --report 路径 --data-dir 路径：验证界面编辑、输入校验、模板渲染和托盘集成，不修改电源设置或启动项。
